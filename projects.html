Projects

  • Persona

    Next.js, FastAPI, PostgreSQL, Google Agent Development Kit, Gemini · Team project, AI Builder Cup

    An e-commerce platform with an AI shopping companion called Pip. Instead of sitting in a chat box in the corner, Pip moves around the page with the shopper, searches and compares products across categories, and hands work to a small team of AI sub-agents. Before confirming a cart change, Pip checks the database to make sure the change was actually saved.

  • Labhya Compute

    FastAPI, Next.js, PostgreSQL, Docker, Tkinter · College project, team of three · MIT

    Most Innovative Project, Ambition Hackathon 2025. A marketplace where people can rent out their idle GPUs by the hour. Hosts run a desktop app that starts a Docker container and opens a reverse SSH tunnel to a relay server; renters connect through the relay using SSH. I later rewrote the Django REST Framework backend in FastAPI.

  • Fingerprint

    FastAPI, React, TypeScript, Gemini Live API · Personal project · MIT

    A tutor that children can simply talk to, entered in the Google Gemini API Developer Competition. It uses Gemini Live for real-time voice conversation, and a backend planner decides when to show a picture, give a quiz, work through an example, look something up, or read a worksheet the child shares.

  • Bookkeeping Platform

  • Football Score Pro

    Python, PySide6, Node.js, Next.js · FutureFrame

    Desktop software for running a football broadcast. The operator sets up squads, formations, kits, officials and on-air guests, then runs the clock, goals, cards, substitutions and penalty shootouts during the match. A service layer with dependency injection and an event bus sits under the PySide6 interface; the repository also has a sample fixtures server and a web match-control dashboard.

  • Football Score Lite

    Next.js, Electron, TypeScript, WebSockets · FutureFrame

    Live match graphics for football and futsal streams: score bug, lower thirds, lineups, substitution and card overlays. The operator works in one window, and a WebSocket server pushes the state to a renderer page that OBS captures and to a commentator view on other devices.

  • In-Browser Image Classifier (LiteRT.js + WebGPU)

    JavaScript, LiteRT.js, WebGPU · July 2026 · MIT · live demo

    A client-side image classifier built the day after Google announced LiteRT.js, its new web AI runtime: MobileNetV2 running entirely in-browser via WebGPU or WebAssembly, no server calls. Includes a live benchmark mode comparing GPU vs. CPU inference latency on the visitor's own device.

  • rustle
